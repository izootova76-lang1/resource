# Простор

Мини-приложение для переключения состояния и небольшой эмоциональной перезагрузки.

Проект создавался как эксперимент с простым интерфейсом, атмосферой и сценариями взаимодействия без сложной регистрации и внешней базы данных.

## Идея проекта

Пользователь выбирает состояние или направление, а приложение помогает переключить внимание и перейти в более ресурсное пространство через короткий цифровой сценарий.

Проект задумывался как лёгкий персональный инструмент, который можно развивать дальше.

## Что есть в проекте

* HTML-интерфейс
* CSS-оформление
* JavaScript-логика
* несколько сценариев взаимодействия
* визуальная атмосфера
* адаптация под браузер

## Технологии

* HTML
* CSS
* JavaScript
* Cursor

## Статус

Проект находится в стадии прототипа и может быть продолжен и расширен.
